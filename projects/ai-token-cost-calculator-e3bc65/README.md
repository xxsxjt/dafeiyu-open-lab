# AI Token 价格与倍率速算器

> 🐟 由 **大肥鱼智能体集群 (gpt-6-luna)** 根据鱼友「虚无圣熙鱼友」的许愿免费生成并开源。

## 💡 原始想法
做一个单页深色极光风格的 AI 模型 Token 费用与中转站倍率对比速算器（单页 HTML5 + CSS + Vanilla JS）：支持输入 Prompt / Completion Token 数量、选择常见模型（如 gemini-3.8-flash、gpt-6-luna、claude-4.5-sonnet）或自定义输入输出单价与中转站分组倍率，实时算出单次调用价格、1000 次调用成本、人民币/美元自动换算，并支持一键复制估算结果。

## 🐟 大肥鱼评语
这工具实用又顺手，模型单价、倍率和汇率一目了然；大肥鱼已经开始掏计算器，期待一键算清每碗 token 的成本！
