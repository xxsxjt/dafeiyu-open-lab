# AI Token 价格与倍率速算器

一个无需安装、无需构建工具的单页 AI API 费用估算器。输入 Token 用量，选择模型和中转站分组倍率，即可查看单次调用、指定调用次数及 1000 次调用的美元与人民币成本。

## 功能特性

- 提供 Gemini 3.8 Flash、GPT-6 Luna、Claude 4.5 Sonnet、GPT-4o、Claude 3.7 Sonnet 等模型预设。
- 支持自定义模型输入与输出单价，单位为 USD / 百万 Token。
- 可填写 Prompt、Completion Token 数量、调用次数、服务商倍率及美元兑人民币汇率。
- 实时展示单次费用、指定次数总成本、1000 次成本和输入输出费用拆分。
- 支持一键复制估算明细；在不支持 Clipboard API 的环境中会尝试使用传统复制方式。
- 深色极光风格响应式界面，适配桌面和移动设备；所有计算在浏览器本地进行。
- 零外部运行时依赖，无需联网、安装或构建。

## 快速运行

1. 下载或克隆项目。
2. 在浏览器中直接打开 `index.html` 即可使用。
3. 也可以从项目目录启动任意静态文件服务器，例如：`python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 定价与计算说明

单次基础费用 = (Prompt Token × 输入单价 + Completion Token × 输出单价) ÷ 1,000,000。应用服务商倍率后得到估算调用费用，并按汇率显示人民币金额。模型预设单价用于演示和快速估算，不保证对应任何服务商的实时价格；使用前请核对实际模型定价、缓存规则、上下文计费方式与汇率。GPT-6 Luna、Gemini 3.8 Flash 和 Claude 4.5 Sonnet 等名称及其价格在本工具中作为可编辑的估算预设，不构成对模型可用性或官方价格的声明。
